## 🧭 Why this profile looks quiet

Nearly everything I build is client work on a company GitLab that you can't see from here. That's
**68 projects since 2019, 19 of them as lead or sole developer**, after an IHK apprenticeship as an IT
specialist for application development. I've spent all of it at the same agency, so I've lived with
my own decisions for years instead of handing them over at go-live.

## 🛠️ How I work

- 🔁 I replace grown PHP/WordPress systems incrementally, in production, without a freeze.
- 🔒 I build REST APIs and webhooks that hold up: rate limiting, CSP, token hashing, path-traversal protection.
- ✅ I wire tests into CI from the start: Vitest, Playwright, PHPUnit.
- 🐳 I run Docker on my own Debian servers, including deployment, TLS, incident analysis and rollbacks.
- 🤖 I build LLM tooling that does real work (OpenAI API, LangChain/LangGraph, MCP, Claude Code), not demos.
